# 🎯 Object Detection and Tracking

An AI-powered Object Detection and Tracking application developed using Python, YOLO, OpenCV and Streamlit as part of the CodeAlpha Artificial Intelligence Internship.

## 📌 Project Description

This application detects and tracks objects in uploaded videos using a pretrained YOLO model. It identifies objects, displays bounding boxes and labels, and tracks objects across video frames.

## ✨ Features

* Upload videos in MP4, AVI, MOV and MKV formats.
* Detect multiple objects using YOLO.
* Display bounding boxes around detected objects.
* Show object labels.
* Track objects across video frames using ByteTrack.
* Display and download the processed video.

## 🛠️ Technologies Used

* Python
* Streamlit
* Ultralytics YOLO
* OpenCV
* ByteTrack

```bash

```
